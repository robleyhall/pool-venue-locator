# Pool Venue Locator

This standalone repository owns venue data, the Python KML generator and exports.
Use Python standard library; no installation or network access is needed to build.
Read README.md and docs/DATA.md before changing data. Preserve evidence dates and
uncertainty; verify new factual venue claims against original sources. Do not
infer table size from total count or league participation from room inventory.

Run `python3 generate_kml.py` and `python3 validate.py` after changes. Commit
exports with source data. Keep this repository focused on public venue information.
